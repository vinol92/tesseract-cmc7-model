Software instalados

Python 3.10.11 (para ejecutar scripts auxiliares del proceso de entrenamiento)

Git 2.51.2  (para descargar el repositorio oficial de tesstrain)


Git Bash (comandos Unix necesaria para ejecutar los scripts de entrenamiento proporcionados por tesstrain)

Chocolatey 2.5.1 (Gestor de paquetes que facilita la instalación segura de herramientas como GNU Make)

GNU Make 4.4.1 (Sistema de automatización utilizado por tesstrain para ejecutar el proceso de entrenamiento paso a paso mediante un Makefile)

Tesseract OCR 5.3.0 (base utilizado para generar los archivos .lstmf y para producir el modelo final)


Tesstrain (repositorio oficial de Tesseract OCR)  (Conjunto de scripts, plantillas y herramientas oficiales para entrenar modelos OCR)

Pillow (Python) (Librería para abrir, procesar y validar imágenes durante la generación de datos de entrenamiento)

NumPy (Python) (Librería matemática usada por tesstrain para operaciones internas mientras crea datos de entrenamiento)
